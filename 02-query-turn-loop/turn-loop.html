  • 故障面（主线走「一切顺利」路径，这些机制收在泳道脚注里）：流式回退 / 模型回退时已产出的 assistant 消息打 tombstone 丢弃、执行器重建（query.ts:953-981、:1152-1177）；message_delta 直接变异已 yield 的消息（部分生效，依赖消费者持同一引用）；中断时为孤儿 tool_use 补合成 tool_result「Interrupted by user」保证 API 配对合法（yieldMissingToolResultBlocks，query.ts:149-179）；abort 后消费者已收到的部分消息不回滚。

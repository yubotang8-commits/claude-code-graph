组件架构：Ink 渲染内核

15-ink-kernel · 组成模块与调用关系

Ink 内核是仓库自带的 React 终端界面框架（Ink 的 fork）：左侧主干把业务 React 树一步步变成终端画面字节；右侧回程把键盘字节一步步变回按键事件送回界面——一去一回构成闭环。

组成模块（实线箭头 = 调用/控制流） 条件分支（仅特定环境触发） 外部组件 / 进程外终端（虚线箭头） 共享底座 灰色小字 = 源码模块锚点（非代码内容）；主干下行 = 画面输出，右路上行 = 按键回流

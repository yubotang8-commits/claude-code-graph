无头 -p 执行全链路

组件 01-cli-entry · 入口与引导

从「claude -p 一句话、或 echo … | claude 管道输入」到「stdout 输出结果、进程带退出码退出」之间发生的全部事情：无头判定 → 精简解析与一次性初始化 → 无头状态仓库与 MCP 接入 → 流式执行逐条输出 → 优雅退出。

深入细节（证据与考据）
  • 证据来源：src/entrypoints/cli.tsx:352-359（默认路径动态加载 main.tsx）、src/utils/earlyInput.ts:31-42（-p/非 TTY 不启动捕获）、src/main.tsx:958-974（无头判定与停止捕获）、src/main.tsx:4603-4610（-p 跳过子命令注册）、src/main.tsx:1087-1097（preAction → init）、src/main.tsx:1030-1064 与 2331（getInputPrompt，非 TTY 时拼接 stdin 管道数据，3 秒无数据则警告放行）、src/main.tsx:3121-3210（--init-only 捷径 / print 分支 / headlessStore 创建）、src/main.tsx:3231-3354（MCP 每服务器增量推送，claude.ai 连接限时 5 秒）、src/main.tsx:3356-3411（动态加载 print.ts 并 void 调用 runHeadless）、src/cli/print.ts:458-578（runHeadless 装配）、src/cli/print.ts:693-806（loadInitialMessages 与输入校验）、src/cli/print.ts:834-848（权限管道与断管兜底）、src/cli/print.ts:877-928（for-await 流式循环）、src/cli/print.ts:930-997（格式化输出与退出码）、src/cli/print.ts:1048-1058（SIGINT 处理）。
  • 关键数据单元：inputPrompt（argv prompt + stdin 管道文本，拼接后作为首条用户消息进入查询）；SDKMessage 消息流（for-await 逐条产出，stream-json 模式逐条写 stdout）；headlessStore（无 React 树时的 AppState 替身，被 runHeadless 闭包持有，settings 变更与 MCP 接入都写它）。
  • runHeadless 是 void 调用（main.tsx:3373）：main.tsx 发起后立即返回，进程收尾由 print.ts 的 gracefulShutdownSync 完成（含 5 秒强杀兜底）；退出码 = 末条 result 的 is_error ? 1 : 0。
  • Ctrl+C：print.ts 的 SIGINT handler 只中止在飞查询再优雅退出（main.tsx:766-772 对 -p 模式特意让位）；父进程先死（断管）由 registerProcessOutputErrorHandlers 兜底（print.ts:848）。
  • --rewind-files 是独立捷径：把文件恢复到指定用户消息状态后直接退出（print.ts:749-784，目标无效则退出码 1）——图中并入「校验失败」分支。
  • 输出格式三态（print.ts:930-974）：text 默认打印末条 result 文本；stream-json 逐条 JSONL（要求 --verbose）；json 输出汇总（verbose 时为全量消息数组，否则仅末条）。
  • 中断后的部分状态：stdout 已流出的行无法撤回；会话 JSONL 已写部分轮次（可用 --resume 恢复）；headlessStore 进程内状态随退出蒸发。恢复路径 = 依赖会话文件重跑。
  • 流式循环内部（每轮 query、工具执行、maxTurns / maxBudgetUsd 截断）属于 02-query-turn-loop 子系统，本图以「主回合循环」概括。
  • 考据注记：无头判定实际还含 --sdk-url 与 CLAUDE_CODE_FORCE_INTERACTIVE 反向门（main.tsx:962-965），图中以「有 -p 或输出非终端」概括；SessionStart 钩子与组织限制校验 validateForceLoginOrg（失败即 exit 1，main.tsx:3163-3169）与 MCP 连接并行发生；main.tsx:4595 注释称跳过 52 个子命令（全文件 .command 注册共 58 处，含嵌套与门控项）；main.tsx 行数随提交漂移（现约 5640 行，文档写 ~5674）。

怎么调用模型：① 把对话 + 工具 schema token 化成 prompt 发给模型（prefill）
② 逐 token 接收 decode 结果 ③ 增量组装成 SSE 事件推给 Agent

  

  

    
🧠 模型 GPU自回归采样

    

    
被调用方式：prompt 一次性 prefill → decode 每步采样 1 个 token → 立即上推（不等整句，这就是流式低延迟的来源）
结束方式：采样到 EOT（turn 结束标记）→ decode 停止 → 推理服务收尾

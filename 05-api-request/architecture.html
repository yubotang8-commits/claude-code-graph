组件架构：API 请求与流式响应

05-api-request · 组成模块与调用关系

「一次模型调用怎么发出去、流式回复怎么接回来」由这些模块协作：核心生成器统一拼装请求并消费流事件；官方通路经重试编排与客户端工厂直达 Anthropic；第三方通路由三个兼容层翻译格式；两条路最终产出同一种内部消息格式，上游主循环完全无感知。

🔄 回合循环 query.ts切片 → 检查点 → 换血继续
每轮迭代回到 autocompact 检查点（query.ts:651）；压缩成功后本轮直接用新上下文继续调 API，对话不中断。失败面：连续失败 3 次熔断后本会话不再自动压缩。
🚦 压缩判定 autoCompact.ts开关 · 熔断 · 守卫 · 阈值
阈值 = 有效窗口 − 缓冲；有效窗口 = 模型窗口 − 2 万（摘要输出预留）；缓冲按窗口分级 13k / 30k / 50k（autoCompact.ts:33-120）。Esc 中止不计失败。
📦 压缩执行 compact.tshooks → 要摘要 → 组装
PreCompact hooks → 生成摘要 → SessionStart hooks → 组装 boundary+摘要+附件（compact.ts:411-651）。摘要请求自身 prompt-too-long 时截头重试 ≤3 次。
🔀 fork 摘要代理 forkedAgent.ts嵌套 query · 复用缓存
fork 与主线程发相同缓存键参数 → prompt cache 命中，17 万输入不重算（forkedAgent.ts:508-575）；失败静默回退直轮流式；压缩期间每 30s 心跳防远程断连。
🖥 消费者 REPL/QueryEngineboundary 落地
REPL 整体替换消息数组（REPL.tsx:3152-3189）；QueryEngine 先 flush 再 splice 截断，崩溃也能 resume（QueryEngine.ts:708-730）；手动 /compact 走同一 compactConversation。

考据注记（源码实读 + flow-evidence）
